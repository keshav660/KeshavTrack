# 🚀 KeshavTrack – Daily Progress Tracker

**KeshavTrack** is a beautifully designed web application made to help you **track your daily progress** in coding, study, or any personal goal.  
Built with `Node.js`, `Express`, and `EJS`, it provides a smooth UI, responsive design, and Hinglish code comments for easy understanding.

## ✨ Features

- 📆 Add your daily progress with date
- ✏️ Edit existing entries
- ❌ Delete with confirmation
- 🧾 View entries in animated horizontal cards
- 🌈 Responsive & beautiful design
- 🇮🇳 Hinglish comments in code (easy for beginners)

---

## 🛠️ Tech Stack

- **Backend:** Node.js, Express.js
- **Frontend:** EJS Templating Engine
- **Middleware:** `method-override`, `uuid`
- **Styling:** Custom CSS with animations
